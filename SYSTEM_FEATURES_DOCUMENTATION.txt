1.1 LOGIN PAGE (index.php)
--------------------------------------------------------------------------------
PAGE DESCRIPTION:
Main entry point for the system. Allows users to authenticate and access
role-specific dashboards (Student, Counselor, or Admin).

VISUAL ELEMENTS:
- System logo/icon (graduation cap icon)
- System title: "Guidance Counseling Management System"
- Login form container with blue gradient header
- Username input field
- Password input field
- Remember me checkbox
- Forgot password link
- Login button (primary blue)
- Create New Account button (secondary)
- Error/success alert messages (dismissible)

USER ACTIONS:
1. Enter username (email address)
2. Enter password
3. Toggle "Remember me" checkbox
4. Click "Login" button
   - System validates credentials
   - Redirects to appropriate dashboard based on role:
     * Student → Student Dashboard
     * Counselor → Counselor Dashboard
     * Admin → Admin Dashboard
   - Shows error message if credentials invalid
5. Click "Forgot password?" link
   - Opens password reset modal
6. Click "Create New Account" button
   - Redirects to Student Registration page
7. Dismiss error alerts by clicking X button

VALIDATION:
- Both username and password are required fields
- Email format validation on username
- Password must match hashed value in database

1.3 FORGOT PASSWORD FLOW
--------------------------------------------------------------------------------
PAGE DESCRIPTION:
Modal-based flow to reset user password via email verification.

VISUAL ELEMENTS:
- Multi-step modal dialog
- Email input field
- Verification code input field
- New password input fields
- Step indicator
- Navigation buttons (Next, Back, Submit)

STEPS:
Step 1: Email Verification
- User enters registered email address
- System validates email exists in database
- Sends verification code to email
- Shows success message

Step 2: Code Verification
- User enters 6-digit verification code
- System validates code
- Enables next step if valid

Step 3: Reset Password
- User enters new password
- User confirms new password
- System updates password (hashed)
- Shows success message
- Redirects to login

USER ACTIONS:
1. Click "Forgot password?" on login page
2. Enter registered email address
3. Click "Send Verification Code" button
4. Check email for verification code
5. Enter verification code
6. Click "Verify Code" button
7. Enter new password
8. Confirm new password
9. Click "Reset Password" button
10. System shows success message
11. User redirected to login page

2.2 BOOK APPOINTMENT PAGE (html/student/book-appointment.php)
--------------------------------------------------------------------------------
PAGE DESCRIPTION:
Comprehensive appointment booking form based on official counseling intake
form. Collects appointment details, student information, medical history,
counseling concerns, and consent acknowledgment.

VISUAL ELEMENTS:
- Multi-section form with clear section headers and icons
- Date and time pickers
- Checkbox grid for counseling concerns
- Text areas for medical information
- Yes/No radio buttons for minor status
- Conditional fields (parent/guardian info if minor)
- Required field indicators (red asterisk)
- Submit button
- Success/error alert messages

FORM SECTIONS:

1. APPOINTMENT DETAILS
   Fields:
   - Appointment Date (date picker, required)
   - Appointment Time (time picker, required)
   
   Visual:
   - Calendar icon for date
   - Clock icon for time
   - Both fields highlighted as required

2. STUDENT INFORMATION
   Fields:
   - Student Name (auto-filled from profile, read-only)
   - Student ID (auto-filled from profile, read-only)
   - Address (text input, required)
   - Are you a minor? (Yes/No radio buttons, required)
   
   Conditional Fields (if minor = Yes):
   - Parent/Guardian Name (text input, required)
   - Parent/Guardian Contact Number (text input, required)

3. COUNSELING CONCERNS (Select all that apply)
   Checkboxes:
   - Academic-Related Concerns
   - Career-Related Concerns
   - Abuse-Related Concerns
   - Adjustment/Adaptation Concerns
   - Parents/Guardian Concerns
   - Relational-Related Concerns
   - Sexuality-Related Concerns
   - Psycho-Emotional Concerns
   - Suicidal Ideation/Tendencies
   - Pregnancy-Related Concerns
   
   Visual:
   - Grid layout (2-3 columns)
   - Checkbox items with borders
   - Hover effect on items
   - Icon for each concern type

4. MEDICAL INFORMATION
   Fields:
   - Current Medications (textarea, optional)
     Placeholder: "List any medications you are currently taking..."
   - Medical Conditions (textarea, optional)
     Placeholder: "List any medical conditions we should be aware of..."
   
   Visual:
   - Medical bag/heart icon in section header
   - Large text areas (4-5 rows)

5. CONSENT AND ACKNOWLEDGMENT
   Elements:
   - Consent statement (read-only text explaining confidentiality and limits)
   - Checkbox: "I acknowledge that I have read and understood the above statement" (required)
   
   Visual:
   - Shield/lock icon for security
   - Bordered consent text box
   - Prominent checkbox with label

6. FORM ACTIONS
   Buttons:
   - "Submit Appointment Request" (primary blue button, full width)
   - Form reset/clear button (optional)

USER ACTIONS:
1. Select appointment date from calendar picker
   - Future dates only (no past dates)
   - Highlights today's date
2. Select appointment time from time picker
   - Business hours (8:00 AM - 5:00 PM suggested)
3. Review auto-filled student information
4. Enter current address
5. Select if student is a minor (Yes/No)
6. If minor, enter parent/guardian name and contact
7. Check all applicable counseling concerns
   - Can select multiple concerns
   - At least one concern should be selected
8. Enter current medications (if any)
9. Enter medical conditions (if any)
10. Read consent statement carefully
11. Check consent acknowledgment checkbox (required to submit)
12. Click "Submit Appointment Request" button
    - System validates all required fields
    - Creates appointment record with status = 'Pending'
    - Updates student address if provided
    - Creates notifications for:
      * Student (confirmation of submission)
      * All active counselors (new request alert)
      * All admins (new request alert)
    - Shows success message
    - Optionally redirects to dashboard

VALIDATION:
- Appointment date must be in the future
- Appointment time is required
- Address is required
- If minor = Yes, parent/guardian fields become required
- At least one counseling concern should be selected
- Consent checkbox must be checked
- All required fields must be filled before submission

SUCCESS MESSAGE:
"Appointment booked successfully! You will receive a notification once a
counselor is assigned."

NOTIFICATIONS CREATED:
1. Student notification:
   "Your appointment request for [Date] at [Time] has been submitted
   successfully. You will be notified once a counselor is assigned."

2. Counselor notification:
   "New appointment request from [Student Name] for [Date] at [Time].
   Concerns: [Top 3 concerns]"

3. Admin notification:
   "New appointment request from [Student Name] for [Date] at [Time].
   Appointment ID: [ID]"

- Time (formatted: "10:00 AM")

   - Scan calendar for days with colored dots
   - Identify days with appointments
   - Click on a day with appointments

   - View session details (student, time, purpose, status)
   - Click "Confirm" button to confirm pending appointment
     * System updates appointment status to 'Confirmed'

   - Click "Close" button
   - Click X button
   - Click outside modal (backdrop)

DATA DISPLAYED:

- Appointment date, time, status
- Associated student names
- Purpose/concern for each appointment

STATUS UPDATES:
When confirming an appointment:
- Database: status changed from 'Pending' to 'Confirmed'
- Notification created for student
- Calendar dot color updates from yellow to green

When cancelling an appointment:
- Database: status changed to 'Cancelled'
- Notification created for student with reason
- Calendar dot color updates to red or removed
